- *Họ và tên:* VŨ TẤN TÚ
- *Mã sinh viên:* 2621050531

## 2. Mô tả bài toán
Chương trình được viết bằng ngôn ngữ *C++* nhằm thực hiện các chức năng cơ bản sau:
- Nhập vào hai số thực bất kỳ a và b từ bàn phím.
- Tính tổng của hai số đó (tong = a + b).
- Tính giá trị trung bình cộng của hai số (trungBinh = tong / 2).
- Hiển thị kết quả tổng và trung bình cộng ra màn hình.

*Thông tin tệp mã nguồn:*
- Tên tệp: tinh_toan_co_ban.cpp
- Ngôn ngữ lập trình: C++

## 3. Hướng dẫn cách chạy chương trình
1. Tải tệp tinh_toan_co_ban.cpp về máy tính (hoặc bấm nút xanh *Code* -> *Download ZIP*).
2. Mở tệp bằng một trong các phần mềm biên dịch C++ như *Dev-C++*, *Code::Blocks* hoặc *Visual Studio Code*.
3. Nhấn phím *F11* (trên Dev-C++) hoặc nút *Run* để biên dịch và chạy chương trình.
4. Nhập lần lượt hai số từ bàn phím, nhấn *Enter* và xem kết quả hiển thị trên cửa sổ Console.
